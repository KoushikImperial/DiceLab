🎲 DiceLab

An interactive dice roller built with HTML, CSS, and JavaScript.

DiceLab is a responsive website where users can roll one or two six-sided dice, view the result, and track their rolling history and statistics.

✨ Features

- Roll one die or two dice at a time.
- Random results from 1 to 6 for each die.
- Animated rolling effect.
- Displays the total of the dice.
- Keeps a history of the latest 10 rolls.
- Shows total rolls, average total, and highest total.
- Clear the current session's history.
- Responsive layout for desktop and mobile screens.

🛠️ Tech Stack

- HTML5 — page structure
- CSS3 — styling, responsive layout, and animation
- JavaScript — dice logic, event handling, history, and statistics

🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.

No additional packages or build tools are required.

📁 Project Structure

DiceLab/
├── index.html
├── style.css
├── script.js
└── README.md

🎲 How It Works

Each die produces a random integer between 1 and 6. JavaScript updates the dice display, calculates the total, and records the result in the session history.
